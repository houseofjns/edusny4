📚 Mid-Term Study Notes

📘 Unit 1: Creative Media

1.1 Start a new document

When you create a document, you will see a blank page.

  • Cursor: The blinking line that shows where your text will appear.
  • Margins: The blank space at the edges of the page.
  • Paragraph break: Press Enter to start a new paragraph (adds a gap).
  • Line break: Press Shift + Enter to move to the next line without a gap.
  • Screen Reader: An assistive technology that reads text out loud.

1.2 Select and change text

  • Fonts: Serif (small lines, easy to read) vs Sans-serif (no lines, modern).
  • Alignment: Left, Center, Right, Justified.

1.3 Add headings and lists

  • Bulleted list: Use when order doesn't matter.
  • Numbered list: Use when order matters.

1.4 Help readers find things

  • Header: Top of every page.
  • Footer: Bottom of every page.
  • Table of Contents: List of headings at the beginning.

1.5 Edit together & finalize

  • Track Changes: Shows edits, can Accept/Reject.
  • Comments: Notes in the margin.
  • Find and Replace: Change words all at once.
  • Spell Checker: Underlines mistakes in red.

📙 Unit 2: Digital Literacy

2.1 Search engines and links

  • Web Browser: Software to access the internet (Chrome, Safari).
  • Search Engine: Website to find info (Google, Bing).
  • Keywords: Short, specific search terms.
  • Hyperlinks: Clickable text that takes you to another page.

2.2 Useful websites & reliability

  • Use quotation marks for exact matches.
  • Check author, update date, fact vs opinion.

2.3 Good and bad

  • Bad side: wrong info, unkind behavior, scams. Tell a trusted adult if upset.

2.4 Bookmarks & images

  • Bookmark: Saves a website link for later.
  • Ask permission before using pictures.

2.5 Stay safe

  • Privacy Settings: Control who sees your profile.
  • Don't share personal info with strangers.
  • Don't open unknown files.

2.6 Give feedback

  • Be positive. Ask: "How would I feel if someone said this to me?"

📗 Unit 3: Computational Thinking

3.1 Think of a number

  • Variable: A place in memory that holds a value.
  • Ask block: Gets information from the user.
  • Answer block: Stores the user's input.

3.2-3.3 Two numbers & total

  • Operator: + - * / symbols.
  • Store answer of number1 + number2 in a 'total' variable.

3.4-3.6 Answer & check

  • Logical Test: Compares two values (answer = total?).
  • If...then: Do something only if true.
  • If...else: Do one thing if true, another if false.
  • Flowchart: Diagram of a program's steps.
